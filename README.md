# 📦 Sistem Inventaris Barang (CLI)

Aplikasi Command Line Interface (CLI) interaktif berbasis Node.js untuk mengelola data inventaris barang secara cepat melalui terminal. *Mini project* ini dibangun untuk mendemonstrasikan operasi CRUD dasar menggunakan struktur ES6 Modules.

## ✨ Fitur Utama
- **Lihat Data Barang:** Menampilkan seluruh daftar barang dalam format tabel rapi (`console.table`).
- **Tambah Barang Baru:** Menerima input nama, kategori, dan stok barang secara dinamis.
- **Update Stok:** Memperbarui jumlah stok barang berdasarkan ID.
- **Hapus Barang:** Menghapus data barang dari sistem.
- **Menu Interaktif:** Navigasi program yang terus berjalan menggunakan `readline/promises` bawaan Node.js.

## 🚀 Cara Menjalankan Program

1. Pastikan [Node.js](https://nodejs.org/) sudah ter-install di komputer.
2. *Clone repository* ini atau *download* foldernya.
3. Buka terminal dan arahkan ke direktori *project*.
4. Eksekusi perintah berikut:
   ```bash
   node main.js
